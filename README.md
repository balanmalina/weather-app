# Weather App 🌤️

A responsive React weather application that displays real-time weather data and short-term forecasts based on the selected location.

## 🌍 Live Demo
👉 https://weather-app-yourname.vercel.app

## ✨ Features
- Search weather by city name
- Displays current temperature, weather condition, wind speed
- Shows humidity, pressure, and visibility
- Short-term weather forecast
- Responsive layout optimized for desktop and mobile

## 🛠️ Tech Stack
- React
- JavaScript (ES6)
- CSS Modules
- OpenWeather API

## 📡 API
Weather data is provided by the [OpenWeather API](https://openweathermap.org/api).

## 📱 Responsive Design
The layout is optimized for common screen sizes and gracefully adapts down to small mobile devices, ensuring usability and readability.
